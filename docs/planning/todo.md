# ParaRisc A/B 均衡分工执行清单

以 [双人分工计划](project-ab-plan.md) 为准。用户承担 A 角色；工作量点数是待校正的初始估计。以下事项尚未标记完成。

## G0：共同冻结接口

- [ ] 确认 A 负责后端、D-cache 与分支预测，B 负责前端/I-cache、统一内存平台、Top、独立参考模型和评测工具。
- [ ] 固定构建版本、公共参数、译码包字段、整包交接和后端输入缓冲。
- [ ] 固定 redirect 与旧包同拍时的优先级、取指路径 ID、预测查询/响应/采用通知、历史恢复和训练带宽。
- [ ] 固定 D/MDU 事务 ID、D-cache 下级内存口的握手/最大在途数、store 确认和最终排空。
- [ ] 共同审定[双发射端口预算](port-budget-and-ipc.md)：PRF 4R2W、两路 ALU/写回/提交、LSQ 两项入队与一路 AGU，以及 Cache/内存仲裁。
- [ ] 确认程序入口、结束、正式内存协议和提交轨迹格式。
- [ ] 建立双方空壳、BackendSink、译码包发生器、MockMemory/MockDCache 与最小测试入口。

## A：后端、D-cache 与分支预测，初始预算 108 点

- [ ] A1（4）：Backend 骨架、前端/统一内存/MDU 替身。
- [ ] A2（16）：RMT/AMT、Free List、PRF/Busy、双重命名与组内依赖。
- [ ] A3（16）：ROB、双提交、物理寄存器回收和分支恢复。
- [ ] A4（16）：RS、唤醒、双发射、旁路和写回仲裁。
- [ ] A5（16）：整数 ALU、实际分支/JAL/JALR、预测器、训练队列和历史恢复。
- [ ] A6（16）：AGU、LSQ、已提交 Store Buffer、访存顺序与事务身份。
- [ ] A7（18）：D-cache、掩码写、脏替换、写回、排空及独立测试。
- [ ] A8（6）：核心、D-cache 与预测器参数实验、架构优化与架构探索报告。

## B：前端与平台，初始预算 92 点

- [ ] B1（14）：公共类型代码、构建工具、Top 骨架、BackendSink 和 MockDCache。
- [ ] B2（8）：PC、取指缓冲、预测查询接入、重定向与旧取指/预测响应隔离。
- [ ] B3（8）：RV32IM 双译码、立即数和完整译码包。
- [ ] B4（12）：I-cache、跨行取指、回填和独立测试。
- [ ] B5（10）：独立 RV32IM 参考模型、提交对拍工具及整机功能验收。
- [ ] B6（12）：I/D 仲裁、统一内存适配、3/20 周期测试模型。
- [ ] B7（16）：八种 M 指令、MDU 背压和数值/RTL 验证。
- [ ] B8（12）：自动评测、综合/时序、平台优化、实验数据汇总与参数敏感度报告。

每个包包含本模块单测、调试和接入，不以清单条数代替工时。G1、G2、G4 更新已投入和预计剩余量；偏离均衡目标时转移完整测试/实验批次或稳定接口叶模块及其验收责任。

## 共同对接与交付

- [ ] G1：真实空壳完成第一次前后端连线；译码包背压/重定向协议通过。
- [ ] G2：宽度 1 后端 + 真实译码/MDU 通过短程序，复核双方剩余工作量。
- [ ] G3：A 的 D-cache、B 的 I-cache/统一内存接通；迟到结果与排空正确。
- [ ] G4：双宽后端、双取指、I/D-cache、MDU 联合回归并再次均衡工量。
- [ ] 用独立整数指令流验证稳态双提交，再用结构冲突测试验证超额请求保留，记录端口等待计数。
- [ ] 通过三项基础程序和要求的 CPU Simulator 程序。
- [ ] 20 周期内存下运行 BenchMark，记录配置、IPC、面积、频率。
- [ ] 每个受支持参数配置通过正确性；完成 CPU、两份报告和复现说明。
